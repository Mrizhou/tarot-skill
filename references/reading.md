# 解读方法

单张牌的含义由脚本打印（关键词、画面、感情/事业/财运、是非）。本文件讲**多张牌怎么串成一个故事**。
解读两张以上的牌阵前读一遍。

## 1. 先看全局

| 看什么 | 怎么判断 |
|--------|---------|
| 大阿卡纳占比 | 超过一半：人生层面的大课题，个人能直接推动的空间较小，重点是顺势和调整心态。不到三成：日常层面，靠具体行动就能改变。 |
| 花色分布 | 某个花色有 3 张以上，或超过三分之一，就是这次的主题（见第 3 节）。某个花色一张都没有，也值得一提，说明这方面暂时不是关键。 |
| 逆位占比 | 超过一半：能量整体受阻、内化，或者时候未到。全是正位：事情比较外显、顺畅。 |
| 宫廷牌数量 | 3 张以上：这件事牵涉很多人，或者关键在于人的性格和互动。 |
| 重复数字 | 同一个数字出现 2 张以上，这个数字的主题会被放大（见第 2 节）。 |

## 2. 数字的含义（小阿卡纳）

| 数字 | 主题 | 例子 |
|------|------|------|
| 王牌（一） | 开始、种子、纯粹的潜力 | 多张王牌：很多新开端同时出现 |
| 二 | 选择、平衡、二人关系 | |
| 三 | 成长、初步成果、合作 | |
| 四 | 稳定、巩固，也可能停滞 | |
| 五 | 冲突、失去、挑战 | 多张五：这段时间摩擦和损耗多 |
| 六 | 调和、给予、过渡 | |
| 七 | 考验、评估、面对自己 | |
| 八 | 行动、推进、改变 | |
| 九 | 接近完成、独处、韧性 | |
| 十 | 完成、终结，一个循环的顶点 | 多张十：一个阶段要结束了 |

## 3. 花色与元素

| 花色 | 元素 | 管什么 |
|------|------|--------|
| 权杖 | 火 | 热情驱动的事业、野心、行动力 |
| 圣杯 | 水 | 情感、关系、直觉 |
| 宝剑 | 风 | 思想、沟通、冲突、决断 |
| 星币 | 土 | 具体的工作、收入、身体、物质现实 |

**元素关系（元素尊严）**：看一张牌时，看它**左右两侧**的牌和它是什么关系；两侧意见不一，就互相抵消一部分。
- **同元素**：互相加强，这张牌的主题更强烈（好的更好，坏的更坏）。
- **相生**：火和风、水和土。互相支持，事情顺。
- **相克**：火和水、风和土。互相削弱，事情里有拉扯和矛盾。
- **弱相生**：火和土、风和水。黄金黎明原版把它们也算作相友，现代读法多简化成「中性」。按「略有支持、影响不大」来读。

大阿卡纳按黄金黎明体系的对应归入元素：
- **风**：愚者、魔术师、恋人、正义、星星
- **火**：皇帝、力量、命运之轮、节制、高塔、太阳、审判
- **水**：女祭司、战车、倒吊人、死神、月亮
- **土**：皇后、教皇、隐士、恶魔、世界

## 4. 宫廷牌：代表人，也代表状态

宫廷牌可以指**某个具体的人**，也可以指**用户自己需要拿出来的状态**。看位置决定：「对方」「他人或环境」位置多半是人；「建议」「自我」位置多半是状态。

| 级别 | 作为人 | 作为状态 |
|------|--------|---------|
| 侍从 | 年轻人、学生、新手、晚辈 | 好奇、学习；也常代表「消息」 |
| 骑士 | 行动派的青年、正在推动事情的人 | 冲劲、推进，事情在变动 |
| 王后 | 成熟、有内在力量的人（多为女性，不绝对） | 用感受和包容掌控局面 |
| 国王 | 成熟、有外在权威的人（多为男性，不绝对） | 用决断和规则掌控局面 |

花色决定这个人的性格：权杖热情直接，圣杯温柔感性，宝剑理性犀利，星币务实可靠。

## 5. 大阿卡纳的三个阶段（愚者之旅）

- **0 愚者**：旅人本身，走完下面三段路的那个人。
- **1–7（魔术师到战车）**：学会在外部世界立足，主题是自我、关系、社会规则。
- **8–14（力量到节制）**：转向内在，主题是品格、取舍、放下。
- **15–21（恶魔到世界）**：面对阴影后超越，主题是执念、崩塌、希望、完成。

多张大阿卡纳时，**按它们在牌阵里的位置顺序**看编号：编号往后走，说明事情在推进；编号往回落，说明在倒退或者绕回老问题。大多落在 15–21，说明是一个大循环的尾声。

## 6. 逆位怎么读

逆位不等于「反义」，按下面四种里最贴合位置和问题的一种读：
1. **受阻**：正位的能量有，但被卡住了。
2. **内化**：发生在心里，还没表现出来。
3. **延迟**：条件还没齐，时候未到。
4. **过度或不足**：正位的特质走了极端，或者严重缺失。

## 7. 相邻牌怎么串

读完单张，**逐对看相邻或有呼应的位置**，给它们的关系定性：
- **因果**：前一张导致后一张。
- **递进**：同一个主题在加深。
- **转折**：前后方向相反。
- **对照**：两张对比着看，比如二择一的 A 和 B、恋人牌阵的你和对方。

有呼应关系的位置一定要对着读：「阻碍」对「建议」，「希望与恐惧」对「最终结果」，「你的心态」对「对方的心态」。

## 8. 常见组合

| 组合 | 常见含义 |
|------|---------|
| 高塔 + 死神 | 旧结构彻底结束，要从头来 |
| 高塔 + 星星 | 崩塌之后的疗愈和希望 |
| 恋人 + 圣杯二 | 很强的感情连接，两情相悦 |
| 恋人 + 恶魔 | 被欲望或执念牵着走的关系 |
| 太阳 + 世界 | 圆满的成功 |
| 月亮 + 宝剑七 | 有隐瞒或欺骗，信息不透明 |
| 宝剑三 + 圣杯五 | 情伤，还沉在失去里 |
| 命运之轮 + 权杖八 | 变化来得很快 |
| 隐士 + 宝剑四 | 需要独处、停下来休整 |
| 圣杯十 + 星币十 | 家庭的情感和物质都圆满 |
| 星币五 + 星币六 | 困境中会得到帮助 |
| 权杖十 + 宝剑九 | 压力过大，已经影响到睡眠和情绪 |
| 皇帝 + 正义 | 规则、合同、法律层面的事 |
| 倒吊人 + 宝剑二 | 僵住了，一直不做决定 |

表里没有的组合，用第 3 节的元素关系和第 7 节的串法自己推。

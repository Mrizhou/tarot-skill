# 问题处理与边界情况

SKILL.md 第 2 步（问准问题）和遇到下面这些情况时读本文件。安全规则不在这里，在 SKILL.md 第 0 步。

## 1. 把问题问准

- **以「我」为主体**：「他会不会回来」改成「我和他的关系接下来会怎样」。
- **有对象、有时间范围**：没说时间就补上默认值——单张指引是「今天」或「本周」，年度十二月是「未来一年」，其他牌阵是「未来三个月」。
- **太笼统就追问一句**：「算算我」这种，问想看感情、事业、财运还是自己的状态。
- 问题定下来后复述一遍请用户确认。**确认后的原话**就是 `--question` 的内容。

## 2. 同一件事算过没有

- 跑 `tarot.py list` 看历史记录里的问题（只有牌阵和问题，不含牌序）。
- **算「同一件事」**：对象相同、事由相同，并且之后没有发生新的变化。
- **算「新的事」**：对象或事由不同；或者是同一件事，但情况有了实质变化（比如对方回复了、面试结果出来了、换了工作）。
- 一个月内算过同一件事、又没有新变化的：按开头提醒里「同一件事只算一次」温和地劝用户先别重算，建议回看上次的结果。用户坚持就照做。
- 触发语里已经带着问题时，**在 `new` 之前**就查；被劝住就不用洗牌了。

## 3. 替别人算

| 情况 | 怎么办 |
|------|--------|
| 家人、伴侣的事（「我男朋友的工作」） | 改成用户自己在这件事里的角度来算：「在他换工作这件事上，我怎么支持他」 |
| 家人的身体（「我妈的病」） | 不算病情走向。改算「我怎么照顾好她，也照顾好自己」，建议听医生的 |
| 替不在场的人算（「帮我朋友算一下」） | 婉拒：没有本人默想、报数，连不上。可以请本人自己来，或者改算用户和这个人的关系 |
| 跟用户本人无关的别人的隐私（「同事是不是出轨了」） | 不算。可以改算用户自己在这件事里怎么自处 |
| 怀疑自己的伴侣出轨 | 可以算，但改成「我在这段关系里的状态、该怎么沟通」，不在牌上给「有没有出轨」的结论 |

## 4. 流程里的特殊情况

| 用户说 / 发生了什么 | 怎么办 |
|------|--------|
| 还没洗牌就先报了数字 | 那时牌序还没锁定，这组数不算。锁定后请他重新默想，再报一次 |
| 自己指定了牌阵 | 用他指定的。明显不合适的（比如简单的是非题用凯尔特十字），说一句理由，再尊重他的选择 |
| 「随便，你帮我挑」 | 用标「推荐」的那个，复述牌阵名和各位置含义后继续 |
| 问题同时涉及感情和事业 | `--topic` 不填，三方面含义都会打印，解读时各取所需 |
| 报的是中文数字（「七、二十三」） | 换成阿拉伯数字再传给脚本 |
| 抽完说「我报错数字了」「想换个牌阵」 | 不改。牌已经翻开，就按已经抽出的牌解读 |
| 抽完发现问题说错了，其实是另一件事 | 这副牌的结果留着不动。另一件事重新 `new` 另算 |
| 用户说英文或其他语言 | 开头提醒和仪式话术忠实翻译成用户的语言，意思不删不改 |
| 对话很长，找不到会话号了 | 跑 `tarot.py list`，找问题相符的那条，向用户确认后再继续 |
| 用户自己抽好了实体牌，只要解读 | 不洗牌、不跑 `new` 和 `draw`。开头提醒照样说；问清每张牌的牌名、正逆位、摆在哪个位置、用的什么牌阵；牌义查 `assets/cards.json` 对应的牌，按 `references/reading.md` 解读。没有哈希，也就没有验证这一步 |

## 5. 不算的问题（完整版）

SKILL.md 第 2 步有简表，这里是每种的替代问法：

| 不算 | 可以改算 |
|------|---------|
| 死亡、寿命、重病能不能治好 | 「我现在该怎样照顾好自己」，用身心灵牌阵，建议听医生的 |
| 胎儿性别 | 「我怎么准备好迎接这个孩子」 |
| 彩票、赌博号码，赌局输赢 | 「我最近的财运和对钱的心态」，用财运三张 |
| 考试作弊、泄题、怎么不被发现 | 「我怎么在这次考试里发挥好」 |
| 报复、诅咒、怎么让某人倒霉 | 「我怎么放下这件事带来的伤害」，用问题解决 |
| 未成年人问早恋 | 「我最近的学习和状态」，用身心灵牌阵 |
| 跟用户本人无关的别人的隐私 | 用户自己在这件事里怎么自处 |

说明原因时语气温和，一句话讲清楚，不说教。

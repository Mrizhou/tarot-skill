# 牌阵库

本文件管**什么问题用什么牌阵**。各牌阵的位置名称和含义的正本在 `assets/spreads.json`，用 `tarot.py spreads` 查看，这里不重复。

## 按问题选牌阵

先判断问题属于哪一类，从「优先」里选推荐，再从「备选」里补 1–3 个给用户挑。

| 问题类型 | 优先 | 备选 |
|---------|------|------|
| 是非题：会不会、能不能、该不该 | 是非牌阵 | 单张指引、时间之流 |
| 某件事接下来怎么发展 | 时间之流 | 马蹄铁、凯尔特十字 |
| 卡住了，想找出路 | 问题解决 | 马蹄铁 |
| 两个选项怎么选 | 二择一 | 问题解决 |
| 感情：有具体对象（伴侣、暗恋、前任） | 恋人牌阵 | 六芒星、时间之流 |
| 感情：没有具体对象（桃花、何时脱单） | 时间之流 | 单张指引、身心灵 |
| 事业：工作、求职、升职、创业 | 事业五张 | 马蹄铁、问题解决 |
| 财运、投资、收入 | 财运三张 | 事业五张 |
| 今天、本周运势 | 单张指引 | 时间之流 |
| 今年运势、未来一年 | 年度十二月 | 凯尔特十字 |
| 人生方向、重大难题、说不清的复杂局面 | 凯尔特十字 | 马蹄铁、六芒星 |
| 状态不对、想了解自己 | 身心灵 | 单张指引、问题解决 |

## 各牌阵的用途

| 牌阵 | 张数 | 用来算 | 不适合 |
|------|------|--------|--------|
| 单张指引 | 1 | 今天或本周的整体提示；给一件事一句话的答案 | 需要看来龙去脉的复杂问题 |
| 是非牌阵 | 3 | 「会不会」「能不能」「该不该」这类只有两个答案的问题 | 「怎么办」「为什么」这类开放问题 |
| 时间之流 | 3 | 一件事从过去到未来怎么走，适用面最广 | 二选一（看不出两个选项的差别） |
| 问题解决 | 3 | 卡在某件事上，想知道问题出在哪、该怎么做 | 想预测结果 |
| 二择一 | 5 | 两个选项之间怎么选：两个 offer、去还是留、分还是合 | 三个以上选项（拆成两两比较）；只有一个选项的是非题 |
| 恋人牌阵 | 5 | 和某个具体的人的关系：伴侣、暗恋对象、前任、复合 | 还没有具体对象（改用时间之流） |
| 六芒星 | 7 | 感情或人际关系的深入剖析，看清双方、环境和结果 | 只想快速知道答案 |
| 事业五张 | 5 | 工作现状、求职、升职、跳槽、创业 | 纯财务问题（改用财运三张） |
| 财运三张 | 3 | 近期收入、开支、投资的整体运势 | 「买哪只股票」这种要具体标的的问题 |
| 马蹄铁 | 7 | 一件具体的事的完整发展，包括暗中的影响和应对办法 | 很笼统的「我的人生」（改用凯尔特十字） |
| 凯尔特十字 | 10 | 复杂、重大、说不清的人生问题，信息量最大 | 简单的是非题，或者想快点知道答案 |
| 年度十二月 | 13 | 未来一年逐月运势，第 1 张是年度主题 | 某件具体的事 |
| 身心灵 | 3 | 最近状态不对，想了解自己的内在 | 问外部事件的结果 |

## 个别牌阵的注意事项

- **是非牌阵**：脚本按每张牌的「是非」值给出判定（是 +1、否 −1、看情况 0；全是「是」为「目前明确倾向是」，全是「否」为「目前明确倾向否」，总分为正、为负、为零分别是「目前倾向是」「目前倾向否」「目前没有定论」）。
  - **先核对问题方向**：每张牌的是非值默认问题是「会不会成、要不要做」。如果问题本身是「该不该离开 / 结束 / 放弃」，像圣杯八（离开）、死神（结束）、宝剑六（离开困境）、权杖十逆位（卸下重担）这类牌，牌义其实是支持离开的，要按牌义重新判断，不能照搬脚本的判定。改判时跟用户说明哪张改了、为什么改。
  - 报判定时用「目前倾向……」的说法，再用牌义说原因和阻碍在哪。
- **二择一**：抽牌前先跟用户确认哪个是 A、哪个是 B，写进 `--question`。位置顺序是 ① 现状 ② A 的过程 ③ B 的过程 ④ A 的结果 ⑤ B 的结果。
- **年度十二月**：脚本会把第 2–13 个位置换成从本月起的实际年月。
- **凯尔特十字**：第 2 张横压在第 1 张上，摆放图里画在第 1 张正下方。

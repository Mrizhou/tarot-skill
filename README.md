## ✨ 特性概览

- **不可篡改的洗牌锁定**：使用 Python `secrets` 洗出 78 张牌与随机正逆位，配合随机 nonce 生成 **SHA-256 哈希**并在占卜前交给你保存；结束后可揭晓原像文件供本地自行核验。
- **克制的触发边界**：只在明确「用塔罗牌算一件事」或「拿实体牌来求解读」时触发；单纯了解塔罗知识、问某张牌含义不会误触发。
- **完整的仪式与解读框架**：覆盖「安全检查 → 开头提醒 → 洗牌锁定 → 默想调焦 → 推荐牌阵 → 报数抽牌 → 串牌解读 → 补牌澄清 → 哈希验证」。
- **零第三方依赖**：仅依赖 Python 3.7+ 标准库，开箱即用；占卜记录保存在用户目录，重装或升级 skill 不丢失。

## 🚀 安装与使用

### 1. 安装 Skill

**方式一：通过 CLI 安装**
```bash
npx skills add Mrizhou/tarot-skill
```

**方式二：下载压缩包手动放入**
1. 前往 [Releases 页面](https://github.com/Mrizhou/tarot-skill/releases) 下载 `tarot.zip` 并解压。
2. 将解压得到的 **`tarot` 文件夹**复制到你所用 AI 工具的 skills 目录（具体目录位置以对应工具文档为准）。

**方式三：Git 克隆**
```bash
git clone https://github.com/Mrizhou/tarot-skill.git tarot
```

> [!IMPORTANT]
> **文件夹名必须保持为 `tarot`**：Agent Skills 规范要求文件夹名称与 `SKILL.md` 中的 `name: tarot` 严格一致，否则部分工具会无法加载。

### 2. 环境要求
- 支持 [Agent Skills](https://agentskills.io/specification) 标准且能执行命令行的 AI 工具
- **Python 3.7+**（只用标准库，无需 `pip install` 任何依赖）
- 占卜记录默认存在 `~/.tarot/records`（独立于 skill 目录，可通过环境变量 `TAROT_RECORDS_DIR` 修改）

### 3. 开始一次占卜

安装完成后，直接对你的 AI 说：

- **线上洗牌占卜**：`「用塔罗牌算一下我最近的工作选择」` / `「帮我抽张塔罗看看今天的指引」`
- **实体牌解读**：`「我自己抽了三张塔罗，帮我解读一下：……」`

> 只是闲聊塔罗或查询牌义（如「塔罗牌是什么」「愚者正位什么意思」）不会触发占卜流程。

## 🕯️ 这套占卜怎么理解

> **一件事占卜过，就定了方向。**  
> 这不是说结局注定会发生。抽出来的牌会在你心里留下印记：你会不自觉地照着它去想、去选、去做；你变了，身边的人和环境也会跟着变。你和你的环境，会一起把这件事往牌指的方向推。
>
> 所以：
> - **问之前想清楚**：问得越准，方向越清楚。
> - **同一件事只算一次**：反复抽不会抹掉上一次，只会把方向搅乱。情况真有了新变化，就算一件新的事，可以再问。
> - **抽到不想要的牌也别慌**：牌指的是照现在这样走下去的方向；方向是被推出来的，看清是什么在推，就知道该在哪儿使劲。
>
> **牌序在洗牌的那一刻锁定，这件事可能的走向，都在这 78 张牌里了。**  
> 接下来你静下心，默想要问的事；你想着它报出的数字，会把属于这件事的那几张找出来。

## 🔮 一次占卜的流程

```text
① 提醒与洗牌 ──▶ ② 默想发问 ──▶ ③ 挑选牌阵 ──▶ ④ 报数抽牌 ──▶ ⑤ 串牌解读 ──▶ ⑥ 补牌/验证
```

1. **提醒与洗牌**：先念开头提醒，再洗牌。78 张牌随机排序、每张随机正逆位，生成一串 SHA-256 哈希给你记下。
2. **默想发问**：闭眼静心，默念你想问的事或人，再告诉 AI。AI 会帮你把问题问准（以「我」为主体、补全时间范围）。
3. **选牌阵**：AI 推荐 2–4 个牌阵，说明各自用来算什么，由你来选。
4. **报数抽牌**：想着这件事，让数字自己浮现，报出几个 `1–78` 的数字（或让 AI 从牌堆顶发牌）。
5. **解读**：画出 ASCII 牌阵摆放图，逐张解读，把牌串成一个故事，最后给出具体、低风险的行动建议。
6. **补牌**（可选）：哪个位置看不明白，默想那个位置的疑问，再抽一张来解释它（每个位置最多补 1 张，单次占卜最多补 3 张）。
7. **验证**（可选）：揭开整副牌，用你第 1 步记下的哈希亲自核对。

## 🔐 哈希是做什么的

哈希做两件事：
- **把占卜的环境固定下来**：洗牌的那一刻，整副牌的顺序和正逆位就定住了，之后抽出的每一张都来自这副已经定住的牌。
- **防止人为改动**：占卜结束后揭开整副牌，用系统自带的工具算一下原像文件的 SHA-256。结果和你第 1 步记下的哈希一模一样（不分大小写），就说明牌序从头到尾没被人动过。

| 系统 | 校验命令 |
|---|---|
| **Windows PowerShell** | `Get-FileHash -Algorithm SHA256 -LiteralPath '<原像文件>'` |
| **Windows 命令提示符** | `certutil -hashfile "<原像文件>" SHA256` |
| **macOS** | `shasum -a 256 '<原像文件>'` |
| **Linux** | `sha256sum '<原像文件>'` |

> [!CAUTION]
> **一定要记下第 1 步的哈希**。能改记录文件的人，也能改完再重算哈希；只有你手里那份才是可靠的对照。原像文件也不要用编辑器打开后另存，否则换行或编码变化会导致哈希对不上。

脚本同时内置多层校验保护：一副牌只能抽一次；每个位置最多补 1 张、一次最多补 3 张；没抽过不能揭晓；揭晓过的牌不能再抽或再补；记录文件若被篡改（牌数不是完整 78 张、会话号不一致等）会直接报错拦截。

## 🛡️ 占卜边界与安全原则

- **不算的问题**（会给出可替代的健康问法）：死亡、寿命、重病能不能治好；胎儿性别；彩票、赌博号码；考试作弊；报复、诅咒；未成年人问早恋；与本人无关的他人隐私。
- **替别人算**：家人、伴侣的事，改从你自己的角度来算；家人的身体状况，改算「我怎么照顾好他」；本人不在场的，不替他算。
- **重大决定**：涉及分手、离婚、辞职、投资理财、就医用药，牌面只提供模糊方向，不给出明确指令。
- **危机干预**：若对话中流露出轻生、自伤的念头，将立即停止占卜，并给出求助渠道（中国大陆：全国统一心理援助热线 **12356**、希望24热线 **400-161-9995**）。

## 🛠️ 命令行参考

平时由 AI 自动调用，如需手动查看历史或核对哈希，可在 `tarot` 目录下运行（Windows 上将 `python3` 替换为 `python`）：

```bash
python3 scripts/tarot.py list                                   # 列出历史会话与哈希
python3 scripts/tarot.py show <会话号>                           # 查看某次占卜的哈希与状态
python3 scripts/tarot.py reveal <会话号> --expect <第1步哈希>     # 揭开整副牌并核对哈希
python3 scripts/tarot.py spreads                                # 查看所有牌阵详情
```

> [!TIP]
> 若在 Windows 终端遇到中文输出乱码，可在 PowerShell 中先执行 `[Console]::OutputEncoding=[Text.Encoding]::UTF8`，其他环境可设置 `PYTHONIOENCODING=utf-8`。

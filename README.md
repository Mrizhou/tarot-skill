# tarot · 塔罗占卜 Skill

一个遵循 [Agent Skills](https://agentskills.io/specification) 开放标准的 skill，任何支持该标准、能执行命令行的 AI 工具都能用。

对 AI 说「用塔罗牌算一下……」，就能完成一次完整的塔罗占卜：洗牌锁定、默想发问、选牌阵、报数抽牌、解读，最后可以验证。
自己抽好了实体牌，也可以直接请它解读。只是想了解塔罗（某张牌什么意思、塔罗怎么来的）不会触发。

## 这套占卜怎么理解

**一件事占卜过，就定了方向。**
这不是说结局注定会发生。抽出来的牌会在你心里留下印记：你会不自觉地照着它去想、去选、去做；你变了，身边的人和环境也会跟着变。你和你的环境，会一起把这件事往牌指的方向推。

所以：
- **问之前想清楚**：问得越准，方向越清楚。
- **同一件事只算一次**：反复抽不会抹掉上一次，只会把方向搅乱。情况真有了新变化，就算一件新的事，可以再问。
- **抽到不想要的牌也别慌**：牌指的是照现在这样走下去的方向；方向是被推出来的，看清是什么在推，就知道该在哪儿使劲。

**牌序在洗牌的那一刻锁定，这件事可能的走向，都在这 78 张牌里了。**
接下来你静下心，默想要问的事；你想着它报出的数字，会把属于这件事的那几张找出来。

## 一次占卜的流程

1. **提醒与洗牌**：先说上面的提醒，再洗牌。78 张牌随机排序、每张随机正逆位，生成一串 SHA-256 哈希给你记下。
2. **默想发问**：闭眼静心，默念你想问的事或人，再告诉 AI。AI 会帮你把问题问准（以「我」为主体、有时间范围）。
3. **选牌阵**：AI 推荐 2–4 个牌阵，说明每个用来算什么，由你来选。
4. **报数抽牌**：想着这件事，让数字自己浮现，报出几个 1–78 的数字。
5. **解读**：画出牌阵摆放图，逐张解读，把牌串成一个故事，最后给出具体的建议。
6. **补牌**（可选）：哪个位置看不明白，默想那个位置的疑问，再抽一张来解释它。
7. **验证**（可选）：揭开整副牌，用你记下的哈希核对。

## 哈希是做什么的

哈希做两件事：
- **把占卜的环境固定下来**：洗牌的那一刻，整副牌的顺序和正逆位就定住了，之后抽出的每一张都来自这副已经定住的牌。
- **防止人为改动**：占卜结束后揭开整副牌，用系统自带的工具算一下原像文件的 SHA-256。结果和你第 1 步记下的哈希一模一样（不分大小写），就说明牌序从头到尾没被人动过。

| 系统 | 命令 |
|------|------|
| Windows PowerShell | `Get-FileHash -Algorithm SHA256 -LiteralPath '<原像文件>'` |
| Windows 命令提示符 | `certutil -hashfile "<原像文件>" SHA256` |
| macOS | `shasum -a 256 '<原像文件>'` |
| Linux | `sha256sum '<原像文件>'` |

**一定要记下第 1 步的哈希**。能改记录文件的人，也能改完再重算哈希；只有你手里那份才是可靠的对照。原像文件不要用编辑器打开后另存，否则哈希会变。

脚本还有几道拦截：一副牌只能抽一次；每个位置最多补一张、一次最多补三张；没抽过不能揭晓；揭晓过的牌不能再抽、不能再补；记录文件被改得不成样子（牌不是完整的 78 张、会话号对不上等）会直接报出来。

## 牌阵

| 牌阵 | 张数 | 用来算 |
|------|------|--------|
| 单张指引 | 1 | 今日或本周运势，一句话答案 |
| 是非牌阵 | 3 | 会不会、能不能、该不该 |
| 时间之流 | 3 | 一件事的过去、现在、未来 |
| 问题解决 | 3 | 卡住了，找出路 |
| 身心灵 | 3 | 了解自己的状态 |
| 财运三张 | 3 | 近期财运 |
| 二择一 | 5 | 两个选项怎么选 |
| 恋人牌阵 | 5 | 和某个具体的人的关系 |
| 事业五张 | 5 | 工作、求职、升职、创业 |
| 六芒星 | 7 | 感情或人际关系深入剖析 |
| 马蹄铁 | 7 | 一件具体事的完整发展和对策 |
| 凯尔特十字 | 10 | 复杂重大的人生问题 |
| 年度十二月 | 13 | 未来一年逐月运势 |

## 边界

**不算的问题**（会给你一个能算的替代问法）：死亡、寿命、重病能不能治好；胎儿性别；彩票、赌博号码；考试作弊；报复、诅咒；未成年人问早恋；跟你本人无关的别人的隐私。

**替别人算**：家人、伴侣的事，改成从你自己的角度来算；家人的身体，改算你怎么照顾好他；本人不在场的，不替他算。

**重大决定**：分手、离婚、辞职、投资理财、就医用药，牌只给模糊的方向，不给明确的指令。

**安全**：对话里流露出轻生、自伤的念头时，不会进行占卜，而是给出求助渠道（中国大陆：12356、希望24热线 400-161-9995）。

## 安装

把整个 `tarot` 文件夹复制到你所用 AI 工具的 skills 目录。各工具的目录位置不同，以它的文档为准。

**文件夹名必须保持 `tarot`**：标准要求文件夹名和 SKILL.md 里的 `name` 一致。

需要 Python 3.7 以上，只用标准库，不用装任何包。

占卜记录存在 `~/.tarot/records`，不在 skill 目录里，重装 skill 不会丢。想放到别处，设置环境变量 `TAROT_RECORDS_DIR`。

## 文件

```
tarot/
├─ SKILL.md                 给 AI 看的流程、话术和规则
├─ README.md                本文件
├─ scripts/tarot.py         洗牌、抽牌、补牌、验证
├─ assets/cards.json        78 张牌：画面、正逆位关键词、感情/事业/财运含义、是非倾向
├─ assets/spreads.json      13 个牌阵的位置和摆放方式
├─ references/spreads.md    什么问题用什么牌阵
├─ references/reading.md    多张牌怎么串起来读
└─ references/questions.md  问题怎么问准、替别人算、特殊情况
```

## 命令

一般不用手动敲，AI 会调用。想自己看的话，在 `tarot` 目录下运行（Windows 上把 `python3` 换成 `python`）：

```bash
python3 scripts/tarot.py list                               # 历史记录和哈希
python3 scripts/tarot.py show <会话号>                      # 某次占卜的哈希和状态
python3 scripts/tarot.py reveal <会话号> --expect <你记下的哈希>  # 揭开整副牌并验证
python3 scripts/tarot.py spreads                            # 所有牌阵
```

输出乱码时：Windows PowerShell 下先运行 `[Console]::OutputEncoding=[Text.Encoding]::UTF8`，其他环境设置 `PYTHONIOENCODING=utf-8`。
